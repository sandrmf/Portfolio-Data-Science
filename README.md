### 📊 Projeto 1: Detecção de Fraudes em Transações Financeiras
Objetivo: Criar um modelo de Machine Learning para identificar transações suspeitas de fraude.
- **Descrição:** Neste projeto, desenvolvi um modelo de machine learning para detecção de fraudes em transações financeiras. Como fraudes são casos raros, utilizei técnicas de balanceamento (SMOTE) e testei diferentes algoritmos.

---

## 📊 Dataset

- **Origem:** Dataset simulado com variáveis anônimas (ex: V1, V2... V28).
- **Classes:**  
  - `0` = Transação Normal  
  - `1` = Transação Fraudulenta

---

## 🧪 Etapas do Projeto

1. **Carregamento e Análise Inicial dos Dados**
2. **Pré-processamento**
   - Normalização
   - Separação em treino e teste
3. **Modelagem**
   - K-Nearest Neighbors (KNN)
   - Árvore de Decisão
4. **Avaliação**
   - Matriz de Confusão
   - Precision, Recall, F1-Score e Acurácia
5. **Visualização**
   - Gráfico de acurácia por valor de K
   - Visualização da árvore de decisão
6. **Balanceamento com SMOTE**

---

## 🧠 Modelos Utilizados

### 🔹 KNN
- Teste com diferentes valores de `k` (1 a 20)
- Melhor acurácia com `k=5`

### 🔸 Árvore de Decisão
- Visualização clara das regras de decisão
- Alta interpretabilidade
- Acurácia final: **95,6%**
